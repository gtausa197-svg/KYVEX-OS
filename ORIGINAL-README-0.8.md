# KYVEX OS

Arch Linux x86-64 desktop, Aurora 0.8 Alpha. KYVEX OS concept and design
adaptation by [gtausa197-svg](https://github.com/gtausa197-svg).

[Rift Native 0.3](rift/README.md) is an experimental Rust + Dynarmic APK runtime.
The current system has one Android execution backend: Native. Waydroid,
its helper, Android image setup, ADB input adapter and libndk installer were removed.

[Current release guide](RELEASE-0.8.uk.md) ·
[Ukrainian system guide](README.uk.md) · [Native architecture](rift/NATIVE-DESIGN.md).

Native has a tested API subset. Commercial APKs in the local test corpus are
not certified or generally playable. Historical 0.4–0.6 guides describe older
releases; their Android compatibility claims do not apply to 0.7.

Source: desktop/ · ISO: archiso/ · build: scripts/ · installer: installer/.
