## [0.8.1] — Aurora Alpha (source snapshot)

The available release documentation describes:

- KDE Plasma 6.8.2 with optional Ryoku/Niri and Xfce sessions.
- Aurora boot theme and Calamares installation integration.
- Standard, LTS and Zen kernels; NVIDIA Open and Mesa packages.
- Arch/AUR/Ryoku/Flathub package integrations and Kali/Parrot via Distrobox.
- PortProton 1.7.5 and experimental RIFT Native 0.3.0.
- Reported 56 automated checks and successful UEFI VM installation.

This repository snapshot **does not** include a bootable ISO or verified final hash.
