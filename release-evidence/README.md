# Release evidence (not a downloadable ISO)

The following text files were supplied separately from the KYVEX 0.8.1 source package:

- `packages-0.8.1.txt`: captured package/version inventory.
- `boot-layout-0.8.1.txt`: xorriso El Torito/hybrid boot metadata.
- `media-uuid-0.8.1.txt`: live medium UUID marker.

These do not establish a final published image checksum or prove wide hardware compatibility. See [release integrity](../docs/RELEASE-INTEGRITY.md).
