# KYVEX OS · Aurora 0.8.0 Alpha

Arch Linux x86_64, KDE Plasma / Wayland та оформлення на основі DuoDesk Aurora.
Ідея KYVEX OS та адаптація дизайну — [gtausa197-svg](https://github.com/gtausa197-svg).
Ліцензії й походження: LICENSE і THIRD_PARTY.md.

Виправлення Live з USB / RAM і NVIDIA RTX 5070: **FIXES-0.3.1.uk.md**.
Поточний випуск: [RELEASE-0.8.uk.md](RELEASE-0.8.uk.md).
Власний Native: **rift/README.md**, перевірки: **VALIDATION-v07.md**.
Старі інструкції 0.4–0.6 описують попередні випуски й не визначають
поточну сумісність Android. Native ще не замінює повний Android Framework.

## Можливості

- GRUB для BIOS і UEFI, тема KYVEX, анімований Plymouth із введенням пароля диска.
- Графічний Live-інсталятор Calamares 3.4.3 з офіційного вихідного коду.
- Standard, LTS і Zen встановлені; Hardened можна додати через головний центр.
- Джерела пакунків: Arch, AUR, Ryoku, Flathub, Kali і Parrot, встановлення,
  відомості, видалення контейнерних пакунків, черга та журнал операцій.
- Менеджер GPU / мережі / аудіо: Mesa, Intel, AMD, NVIDIA Open, Nouveau та гілки NVIDIA з AUR.
- PortProton для EXE та MSI, Ryoku Settings і додаткова сесія Ryoku (Niri).
- Bazaar, Discover, Flatpak із Flathub, монітор системи Plasma, Kate, Ark,
  Gwenview, Firefox, Konsole, Dolphin та базові кіберінструменти.
- nftables, auditd, заблокований root, SSH не запускається автоматично.
- Центр продуктивності: тимчасовий профіль CPU / GPU, пріоритет вибраної
  програми, пауза індексації, zram, датчики та власний порівняльний тест рендеру.

## Live і встановлення

Перевірте SHA256 образу. Для VM рекомендовано 4 ядра та 8–10 ГіБ RAM;
Calamares вимагає щонайменше 3 ГіБ RAM та диск від 24 ГіБ.
Для великої колекції кіберпрограм потрібен значно більший диск.
Secure Boot у цьому випуску не налаштовано.

Live-вхід: **kyvex / kyvex**, автоматично. Root заблокований; адміністративні
дії підтверджуються через PolicyKit. Англійська мова за замовчуванням; українська
доступна в налаштуваннях. US / UA через Alt + Shift,
типовий часовий пояс UTC. Super — меню; Super + Enter — термінал.

Тимчасове сховище Live обмежене 60% RAM і не зберігає зміни після перезавантаження.
Усі великі набори встановлюйте у встановленій на диск системі.

Відкрийте **Центр KYVEX → Встановлення → Встановити KYVEX OS**.
Calamares запропонує мову, розташування, клавіатуру, розділи, користувача та
підсумкове підтвердження. Автоматична схема має EFI за потреби, окремий
незашифрований /boot на 2 ГіБ і кореневий ext4, за бажанням — LUKS2 для кореня.
Є також ручне розбиття. Підтверджене форматування знищує дані вибраних розділів.

Базова система копіюється з ISO без інтернету. Старий текстовий інсталятор
0.1 замінено запуском Calamares; команда kyvex-install більше не форматує диск.
Запуск майстра дозволено лише у Live-сесії за наявності системного образу.

## Репозиторії й Cyber Hub

Натисніть «Підключити» біля Kali / Parrot та дочекайтеся завершення черги.
Rootless Distrobox / Podman створює середовище з офіційного образу, а APT
оновлює його індекси. «Підключено» означає успішне завершення налаштування.

Порожній пошук показує повний індекс обраного джерела з поступовим додаванням
карток. Фільтр «Набори інструментів» знаходить метапакунки, зокрема
kali-tools-forensics, kali-tools-web, kali-linux-everything, parrot-tools-full.
Усі інструменти доступні для завантаження за потреби, а не запаковані в ISO.
Великі набори можуть займати десятки або сотні гігабайтів.

Офіційні джерела:

- docker.io/kalilinux/kali-rolling:latest — Kali rolling / http.kali.org.
- docker.io/parrotsec/core:latest — репозиторії образу Parrot / deb.parrot.sh.
- Arch core / extra — нативні підписані пакунки через pacman.

Образ містить початковий індекс Arch для пошуку без першого повного оновлення.
Перед установленням нативного ПО виконується повне оновлення Arch; індекс у
образі є знімком на момент збірки. Пошук у фільтрі наборів також враховує запит.

APT-репозиторії не додаються до pacman: залежності й ключі залишаються в
середовищі відповідного дистрибутива. Distrobox інтегрується з робочим столом;
це не захисна ізоляція для шкідливих файлів. Wi-Fi monitor mode, модулі ядра та
прямі апаратні операції можуть потребувати нативних інструментів і окремих прав.

## Ядра, драйвери, застосунки

«Ядра Linux» дозволяють установити / оновити, вибрати типове для GRUB або
видалити невикористовуване ядро. Поточне та останнє ядро захищені від видалення.
Зміна типового ядра доступна після встановлення й потребує перезавантаження.
У Live ядро обирають у GRUB.

Zen налаштоване для інтерактивного робочого столу; результат залежить від
обладнання. LTS має тривалу підтримку, Hardened — додаткові обмеження захисту.

«Драйвери» показують виявлені пристрої й активні модулі. NVIDIA Open
перевіряється за таблицею PCI від NVIDIA для версії драйвера; непідтримуваний
GPU відхиляється до встановлення драйверного пакунка. Для DKMS додаються
заголовки встановлених ядер. Фізичне перепрошивання не виконується профілем
firmware; сумісні оновлення прошивок можна окремо переглянути в Discover / fwupd.
Це менеджер KYVEX на Arch; mhwd і репозиторії Manjaro не змішуються з Arch.

## Продуктивність

Відкрийте **Центр KYVEX → Продуктивність**, оберіть власну програму й увімкніть
профіль. Для звичайної роботи доступний профіль робочого столу. Центр показує
фактичні зміни та можливості обладнання. Після завершення програми, вимкнення
профілю або спливу часу попередні налаштування відновлюються.

«Перевірити рендер» запускає два однакові проходи FFmpeg і зберігає виміряний
результат. Перевага залежить від обладнання й навантаження; 10–15% не гарантуються.
Докладний опис, обмеження та керування: **PERFORMANCE.uk.md**.

## Збірка та перевірки

Потрібні Linux ext4/btrfs, root, archiso, grub, mtools, Python/Pillow, librsvg,
ttf-dejavu і залежності Calamares; приблизно 25–35 ГіБ для збірки плюс місце VM.

Calamares: https://codeberg.org/Calamares/calamares.git, v3.4.3,
ревізія af2eaf829b7c60ae5b69b9fe68f9158dc98d3331.
Скрипти: v02-build-deps.sh, compile-calamares.sh, package-calamares.sh,
generate-v02-artwork.py та build-iso.sh у каталозі scripts.
Локальний пакунок підписується; приватний ключ не включається до ISO.
Поточні скрипти використовують D:\KYVEX-OS і WSL2 KYVEX-Builder; для іншого
хоста слід адаптувати шляхи. Rolling-дзеркала не заморожені.

Контрольна сума, точний склад та фактичні тести — у VALIDATION-v031.md і маніфесті
випуску. Перевірка VM не підтверджує сумісність усіх фізичних GPU, Wi-Fi і ноутбуків.
