# Security policy

## Supported status

KYVEX OS 0.8.1 is **Alpha**. No stable, security-supported release series is claimed in this repository snapshot.

## Reporting a vulnerability

If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise, contact the maintainer through the contact information published on their [GitHub profile](https://github.com/gtausa197-svg); avoid putting exploit steps, sensitive keys, or private user data in public issues.

A report should include affected versions, reproduction steps, impact, configuration, logs (redacted), and a proposed fix where possible. There is no public promise of a response time or bounty program.

## Limitations

RIFT Native is not a security-certified Android sandbox. Distrobox integrates with host resources and is not by itself a containment boundary for malicious code. Optional LUKS2 encryption is configuration-dependent.
