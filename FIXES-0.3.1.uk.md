# KYVEX OS 0.3.1 · Live USB та RTX 5070

## Live-установник

З USB Archiso може автоматично перенести airootfs.sfs у RAM та відмонтувати
bootmnt. Версія 0.3 шукала файл лише у bootmnt і блокувала встановлення.
Попередній тест із віртуального CD не запускав цей автоматичний режим.
Тепер центр і установник перевіряють справжні монтування запущеної системи,
знаходять backing file її squashfs, зокрема copytoram, і передають Calamares
стабільний шлях /run/kyvex/live/airootfs.sfs. Підроблений Live-прапорець у
встановленій системі не дозволяє запуск. Оновлення os-release більше не приховує
Live; додатковий hook зберігає брендування після оновлення пакунка filesystem.

Окремо виправлено пошук носія у GRUB: гібридний ISO містив HFS+ розділ із тією
самою міткою, що й ISO9660. Пошук за міткою іноді обирав неправильний розділ.
Тепер використовується UUID файлової системи, а після розпакування ISO на флешку —
унікальний файл-маркер і UUID знайденої файлової системи.

Перевірено завантаження образу як USB, автоматичне копіювання в RAM, запуск
Calamares без bootmnt, повне встановлення на тестовий диск 32 ГіБ і запуск
встановленої системи без ISO. Результати: **VALIDATION-v031.md**.

## NVIDIA / Radeon 860M + RTX 5070

У 0.3 не було готових модулів NVIDIA у Live. 0.3.1 включає офіційні Arch-пакунки
NVIDIA Open DKMS / nvidia-utils 615.78.08, nvidia-settings, PRIME та заголовки
Standard / LTS / Zen. Модулі зібрано для кожного ядра і включено в initramfs
разом із GSP firmware. DRM modeset / fbdev увімкнені до Plymouth / Wayland;
пакунок NVIDIA блокує конфліктні nouveau / nova. AMD та Intel зберігають свої драйвери.

Почніть із **Standard** у GRUB. Якщо на RTX 5070 артефакти залишилися,
оберіть **Graphics compatibility**. Це вимикає DRM modifiers, використовує
програмний курсор, обмежує буферизацію й переводить Qt Quick / центр на програмне
малювання. Режим може бути повільнішим; звичайний запуск зберігає прискорення.
У встановленій системі: **Центр → Драйвери → Сумісність графіки**; зміна
застосовується після перезавантаження. Режим сумісності, обраний у GRUB Live,
переходить у встановлену систему. У Live заміну драйверів та ядер заблоковано,
щоб не порушувати відповідність драйвера запущеному ядру повним rolling-оновленням.

Користувач повідомив: перемикання виконується у BIOS, на Radeon 860M усе добре,
на RTX 5070 — артефакти; USB створено Rufus у режимі ISO. Це враховано у зміні.
Linux-тести виконуються у VM без прямого доступу до RTX 5070, тому вони не
підтверджують відсутності артефактів на конкретному ноутбуці. Ідентифікатор
карти з Windows, 10de:2d18 / 17aa:8002, звірено з таблицею підтримки драйвера.

## Застосування

Перезапишіть флешку новим ISO 0.3.1; старий носій самостійно не оновиться.
Перевірте SHA256. Рекомендований запис у Rufus — **DD**, який зберігає гібридний
образ без перетворення. Саме прямий образ перевірено як USB у VM; фізичний запис
Rufus у режимі ISO на конкретну флешку тут не перевірявся.
Вхід Live: **kyvex / kyvex**. Secure Boot поки не налаштовано.
Відкрийте **Центр → Встановлення**. Розділи й остаточне підтвердження — у Calamares;
сам запуск майстра не форматує диск.

Якщо артефакти залишилися навіть у режимі сумісності, завантажтеся через Radeon
і збережіть звіт: `sudo kyvex-diagnostics > ~/kyvex-diagnostics.txt`.
Він містить GPU, версії модулів, стан Live та відповідні повідомлення ядра.
Автоматичного надсилання немає.
