# KYVEX OS 0.4.0 Alpha — Performance та App Bridge

Англійська є типовою мовою Live / Plasma / центру. У центрі: Appearance → Language.
Доступні українська та часткові польська й німецька з англійським fallback.
Мова центру зберігається у профілі користувача; мову всього робочого столу
змінюють у налаштуваннях KDE. Локалі en_US, uk_UA, pl_PL, de_DE включено.

## Продуктивність

Таймерів завершення обох профілів більше немає. Профіль програми завершується
разом із цільовою програмою або вручну. Профіль робочого столу — вручну або
після завершення користувацького сеансу; закриття центру його не вимикає.
Аварійне завершення служби виконує відновлення. Нове налаштування ручних частот
недоступне, поки активний профіль оптимізації чи незавершене відновлення.

Performance → Gaming / hardware controls: CPU min/max у межах cpuinfo,
доступні governor / EPP / профілі живлення; AMD — рівні DPM; NVIDIA —
обмеження частоти через nvidia-smi, якщо це дозволяє обладнання. Без зміни напруг,
прошивок та overdrive. Зміни тимчасові до скидання / перезавантаження.
Reset повертає збережені CPU-налаштування, а NVIDIA — типове керування частотами.
Відмова ноутбучного драйвера показується у журналі операції.

## Windows

Wine 11.21, Mono, Gecko та Winetricks включені. Двічі натисніть EXE або MSI;
App Bridge також має вибір файла, Wine settings і Lutris. Bottles встановлюється
окремою кнопкою з Flathub; його runners / DXVK / VKD3D завантажуються менеджером.
Wine використовує користувацьке середовище ~/.local/share/kyvex/windows/default.
Це ізоляція налаштувань, не захисна ізоляція файлів.

binfmt_misc передає MZ/PE до користувацького Wine-лаунчера; це інтеграція
з механізмом завантаження Linux, а не реалізація ядра Windows. Windows-драйвери,
деякі античити, DRM та окремі складні програми можуть не працювати.
Лаунчер перевіряє PE/MSI, не запускає файли з правами root і зберігає журнал
останнього запуску в ~/.local/share/kyvex/logs/windows.log.

## Android та ARM

Waydroid 1.6.3 використовує ядро Linux / binderfs і працює у Wayland.
У встановленій KYVEX: App Bridge → Set up Android завантажує офіційний Vanilla
образ. Start Android запускає сеанс; Open APK / подвійне натискання встановлює
APK й запускає його пакет. Увімкнено multi_windows. Waydroid Helper 0.2.9
надає редактор клавіш / миші / сенсорних зон; F1 перемикає редагування й керування.
У його upstream-сервісі спільних папок заблоковано неавтентифіковані D-Bus
запити звичайних користувачів на довільні монтування; редактор клавіш збережено.

**ARM32 / ARM64:** запустіть Android, тоді Enable ARM translation. Для AMD CPU
та Android 13 додано завантаження libndk_translation з фіксованої ревізії
faece8cc787a520193545116501cad40534063fc (R125, Android 13), SHA256
235b31e75cd62fe18a6d11f4772df096c767d0d0252ef7eb7a2aeb56448ba915.
Перевіряються CPU, версія Android, контрольна сума, структура архіву та відсутність
іншого bridge. Включено конфігурацію arm64-v8a та armeabi-v7a. Після встановлення
перезапустіть Android-сеанс. Бінарники libndk не перерозповсюджуються в ISO;
ліцензія зберігається разом із завантаженим компонентом. Для інших CPU / версій
Android потрібен інший сумісний bridge з відповідною ліцензією.

Для першого запуску редактора клавіш відкрийте Start Android, у Waydroid Helper
натисніть Open у Key Mapper та підтвердьте локальний ключ у вікні Android
«Allow USB debugging». Після підтвердження повторіть Open. Доступ обмежений
приватною мережею Waydroid; зовнішні вхідні підключення firewall не відкриває.

Під час перевірки VLC 3.6.5 ARM64 та ARM32 відкривався окремим вікном і декодував
тестовий відеофайл. Termux ARM64 встановився, але його початкове середовище не
пройшло bootstrap; цей застосунок не позначено як сумісний. ARM-переклад не
гарантує роботу всіх ігор. Для зміни архітектури вже встановленого APK може
знадобитися видалення старої версії зі збереженням власних даних перед цим.

ARM native bridge стосується Android APK з ARM-бібліотеками, не довільних
виконуваних файлів ARM для будь-якої ОС. Google-сервіси, Play Integrity,
банківські застосунки та DRM не гарантуються. За відсутності render-пристрою
AMD / Intel первинне налаштування обирає документований програмний SwiftShader
(зокрема для NVIDIA-only та VM без прискорення). На Radeon використовується Mesa.

## Пам’ять GPU

Центр показує VRAM та, де надано драйвером, спільну GTT-пам’ять.
Розміщення й перенесення буферів виконує драйвер / менеджер пам’яті ядра.
Універсального примусового вивантаження всіх VRAM-буферів без участі програми
немає; RAM має інші затримки та пропускну здатність. KYVEX не видає RAM за
додаткову фізичну VRAM і не видаляє активні GPU-буфери.
