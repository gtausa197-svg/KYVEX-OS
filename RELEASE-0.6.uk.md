# KYVEX OS 0.6 Alpha — Rift Native 0.2

У цьому випуску додано власне легке середовище виконання на Rust із CPU JIT
Dynarmic. Воно працює без повного образу Android: читає справжній DEX, виконує
Java-методи, завантажує ARM32/ARM64 ELF-бібліотеки, обробляє частину JNI та
відображає базові Android-віджети в окремому вікні Linux.

Це робочий експериментальний прототип із невеликим набором API. Він ще не
замінює Android для довільних застосунків. Unity, повний Android Framework,
графічні рушії, звук, сервіси, multidex і JNI_OnLoad потребують подальшої
розробки. Subway Surfers запускається через попередній режим Compatibility;
підтримки цієї гри в новому Native немає.

## Як перевірити

1. Завантаж ISO. Для комп’ютера з 4 ГіБ ОЗП вибери **Light Live + Rift Native**
   у GRUB. USB залишається підключеним: система читає образ із нього.
2. Live-вхід: **kyvex / kyvex**. У легкому Live автоматично відкриється
   Rift Studio. На головному робочому столі Studio доступне через меню програм
   і KYVEX Control Center → Android / Rift.
3. У бібліотеці натисни **Try Native demo**. Інтернет і налаштування Waydroid
   не потрібні; власний тестовий APK уже включено.
4. У вікні програми натискай **Run ARM calculation**: значення 7, 14, 21
   обчислює ARM-бібліотека через Java/JNI, а не інтерфейс Studio.
5. У **Game Controls** вибери архітектуру **armeabi-v7a** або **arm64-v8a**,
   середовище **native** та профіль пам’яті **light / balanced**. Зміни
   застосовуються при наступному запуску. Старі програми зберігають
   **compatibility**, доки ти явно не зміниш цей вибір.

Native не перемикається автоматично на інший рушій. Непідтримувані API,
інструкції, бібліотеки й формати зупиняють запуск із поясненням.
Імпорт APK лише додає його до бібліотеки; код виконується після запуску.

## Пам’ять і захист процесу

Light: до 32 МіБ відображених сторінок гостя, 4 МіБ Java heap, 8 МіБ JIT cache,
192 МіБ адресного простору процесу. Balanced: 96 / 16 / 16 / 384 МіБ.
Це окремі обмеження, а не обіцянка споживання всієї системи. Сторінки
виділяються за потреби. Studio й робочий стіл використовують додаткову ОЗП.
Вікно показує фактично виміряний пік RSS процесу та кількість подій/викликів.

Тимчасові Java-об’єкти прибираються між подіями. Одночасно працює один Native
застосунок на користувача. Закриття вікна завершує й прибирає процес.
Бюджети інструкцій і часу відповіді зупиняють завислий код. Загальний CPU-час
одного процесу обмежено 30 секундами обчислень; очікування введення не
витрачає цей CPU-бюджет.

Процес працює без root, успадкованих файлових дескрипторів і загальних API
файлів/мережі; має Linux seccomp-фільтр та ліміти ресурсів. Це не результат
незалежного аудиту безпеки. Dynarmic — відкритий сторонній CPU-компонент;
власні частини KYVEX та сторонні ліцензії описано в THIRD_PARTY.md.

## Межі випуску

Native приймає окремі APK до 64 МіБ з одним classes.dex до 8 МіБ.
Підтримується базовий Activity, вертикальний LinearLayout, TextView, Button,
частина Java-операцій, ARM32/Thumb/ARM64 і вузький набір JNI/Bionic.
Повноцінне збереження стану Android-програми й перевірка довіри до підпису
APK ще не реалізовані. Повторний запуск демо починається з початкового стану.

Compatibility зберігає Waydroid і окреме встановлення libndk. Для ігор у цьому
режимі в Live рекомендовано 24 ГіБ ОЗП та інтернет для першого налаштування.
У Live встановлені програми й профілі зникають після перезапуску.
