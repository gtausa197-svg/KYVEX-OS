# KYVEX OS 0.2 Aurora Alpha — фактичні перевірки

Дата: 2026-11-01. Середовище: QEMU / KVM, q35, Virtio GPU та мережа,
4 CPU, 8 ГіБ RAM. UEFI: OVMF; BIOS: SeaBIOS. Фізичні диски хоста
не передавалися до віртуальної машини.

## Завантаження та встановлення

- Live завантажено через BIOS і UEFI до Plasma / Wayland та центру KYVEX.
- Власні GRUB і Plymouth перевірено на реальному завантаженні VM.
- Calamares 3.4.3 пройшов усі сторінки майстра й завершив установлення.
- Тест: окремий віртуальний диск 32 ГіБ, GPT, EFI 512 МіБ, /boot ext4
  2 ГіБ, корінь ext4 у LUKS2, без swap, окремий користувач без автовходу.
- ISO від’єднано. Встановлена система завантажилася через UEFI fallback;
  Plymouth прийняв пароль LUKS2, SDDM — пароль користувача, відкрилася Plasma.
- У встановленій системі KYVEX_LIVE=0, корінь розташований у /dev/mapper/luks-*.
- graphical.target, sddm, NetworkManager, nftables та auditd активні.
- Установник відхиляє запуск зі встановленої системи без Live-образу.

Під час інтеграційного тесту виявлено відсутність службових монтувань
у Calamares. Додано /proc, /sys, /dev, /run, /run/udev та efivarfs.
Повторний повний запуск Calamares завершився успішно.

## Репозиторії та програми

Тести виконували реальний manager.cjs у Live VM, без підміни процесів:

| Джерело | Фактичний результат |
| --- | --- |
| Kali | Офіційний образ завантажено, APT оновлено; пошук nmap, 39 метапакунків; Nmap 7.991 установлено і запущено |
| Parrot | Офіційний образ завантажено, APT оновлено; пошук nmap, 16 метапакунків; Nmap 7.95 установлено і запущено |
| Arch | Індекс core/extra відновлено; пошук nmap повернув 4 результати й позначив установлений nmap |
| Flathub | Реальний remote https://dl.flathub.org/repo/ присутній у Live та встановленій системі |
| Bazaar | Запущено з центру; завантажив і показав реальний каталог Flathub |
| Монітор Plasma | Відкрив процеси, CPU, пам’ять і мережеві дані |

Cyber Hub показав підключені Kali / Parrot і результати пошуку у справжній
графічній сесії. Жодних сканувань сторонніх мереж не проводилося.
Лічильники та версії репозиторіїв змінюються з часом.

## Ядра й драйвери

- Встановлені linux 7.2.11.arch1-1, linux-lts 6.18.60-1,
  linux-zen 7.2.11.zen1-1; Calamares створив initramfs для кожного.
- Встановлена система завантажила Zen 7.2.11-zen1-1-zen до робочого столу.
- Через центр KYVEX вибрано LTS, підтверджено PolicyKit, оновлено GRUB.
  Після перезавантаження працює 6.18.60-1-lts; відкрито Plasma й центр.
- Вибір початкового Standard явно задано в GRUB; зміна типового ядра
  перевірена за фактичним порядком записів grub.cfg.
- Виявлено PCI Virtio GPU та мережу з активними драйверами.
- Перевірки NVIDIA порівнюють PCI/OEM ID з таблицею поточної версії драйвера;
  установка на фізичну NVIDIA / AMD / Intel у цьому тесті не виконувалася.

## Автоматизовані перевірки

- 9 тестів Node: фіксовані команди, неприйнятні параметри, маршрутизація
  джерел, ізоляція Electron, розрахунок місця для залежностей APT — пройдено.
- 9 тестів Python: привілейований помічник, захист ядер, NVIDIA,
  перевірка Live-носія та службових монтувань установника — пройдено.
- Конфігурації модулів Calamares перевірено схемами офіційної версії — пройдено.
- Electron UI smoke: пошук, картки, дії, сторінки ядер / драйверів / застосунків /
  установлення, компактне вікно, обмеження renderer і зменшення анімацій — пройдено.
  Дані репозиторіїв у цьому UI harness є фікстурами; реальні перевірки наведені вище.
- Окремо перевірено пошук Arch і пошук за запитом усередині наборів інструментів.

Тестова VM мала додаткову serial-консоль для діагностики; ця зміна не входить
до звичайного встановлення. Кінцеві налаштування початкового індексу Arch і
Standard синхронізовано з тестовою системою перед повторною збіркою ISO.

## Межі цієї перевірки

Це Alpha. Не перевірено встановлення Calamares через BIOS, усі ручні схеми
розділів, усі варіанти swap, Secure Boot, реальні GPU / Wi-Fi / ноутбуки,
установлення кожного пакунка чи всіх великих метапакунків. Secure Boot не
налаштовано. У Virtio VM немає повної телеметрії фізичного GPU, тому монітор
Plasma може попереджати про відсутній датчик GPU. Вимірів переваги Zen у
швидкодії не проводилося. Distrobox не є ізоляцією для шкідливих файлів.

Контрольна сума, розмір остаточного ISO й склад пакунків постачаються окремо
разом із файлами випуску. Джерела й ліцензії описані в THIRD_PARTY.md.
